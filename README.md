# Soil Fertility Classification Using Machine Learning

BCA Project Based Learning (PBL).

## Files
- `Soil_Fertility_Classification.ipynb`: complete notebook with data cleaning, EDA, visualizations, correlation, feature selection, four classifiers, evaluation, feature importance, unseen-sample prediction and an interactive Jupyter prediction UI.
- `soil_fertility_classification_1000.csv`: supplied CSV dataset.
- `Dataset_README.txt`: original dataset documentation.
- `requirements.txt`: required Python packages.

## Run
1. Extract the ZIP.
2. Open this folder in Jupyter Notebook/JupyterLab.
3. Install dependencies: `pip install -r requirements.txt`
4. Open `Soil_Fertility_Classification.ipynb`.
5. Run all cells from top to bottom.
6. The notebook saves the trained model and CSV result files after execution.

## Dataset limitation
The supplied documentation describes the 1,000 rows as source-calibrated synthetic teaching data, not 1,000 authentic laboratory observations. The fertility class is a derived teaching label based on N, P, K, organic carbon, pH and EC. Do not present model performance as validated real-world soil diagnosis.
